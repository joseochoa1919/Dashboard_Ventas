# 📊 Dashboard de Ventas

Dashboard interactivo desarrollado con Python, Pandas, Plotly y Streamlit.

## Objetivo

Analizar las ventas de una empresa peruana durante el año 2026 mediante indicadores y gráficos interactivos.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit

## Indicadores

- Ventas totales
- Número de transacciones
- Unidades vendidas
- Ticket promedio
- Ventas mensuales
- Ventas por categoría
- Ventas por ciudad
- Ventas por vendedor

## Archivos

- `app.py`: código principal del dashboard.
- `base_datos_ventas.csv`: base de datos ficticia generada con IA/Python.
- `requirements.txt`: librerías necesarias para ejecutar el proyecto.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicación

El proyecto puede conectarse a GitHub y desplegarse mediante Streamlit Community Cloud.
